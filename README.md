# Enspct modularity POC

The React app and Express API are separate pnpm packages. The demo uses Grievances, Inspections, and Facilities to verify module ownership, code splitting, permissions, translations, and server-side pagination.

```text
enspct-modularity-poc/
├── lefthook.yml
├── package.json
├── web/
│   ├── vite.config.ts
│   ├── .dependency-cruiser.cjs
│   ├── knip.json
│   ├── scripts/               # Boundary and removal demos
│   └── src/
│       ├── core/              # Shared shell, API, permissions, and i18n
│       ├── modules.ts         # Enabled manifests for navigation and locales
│       ├── routes.ts          # Enabled TanStack virtual route fragments
│       ├── routeTree.gen.ts   # Regenerated by Vite
│       └── modules/
│           ├── grievances/    # Manifest, route, page, API client, EN/AR locales
│           ├── inspections/   # Same module layout
│           └── facilities/    # Same module layout
└── server/
    └── src/
        ├── index.ts           # Express, demo permissions, and list endpoints
        └── data.ts            # In-memory fixtures and pagination
```

## File routing

The Vite TanStack Router plugin generates `src/routeTree.gen.ts`. The virtual configuration in `src/routes.ts` directly mounts each module's physical route directory using `physical()` from `@tanstack/virtual-file-routes`.

For example, `modules/facilities/routes/facilities.tsx` maps to `/facilities`. A new `facilities.$facilityId.tsx` in that directory becomes a nested parameter route through file discovery. Route files export `createFileRoute()` definitions. Module removal still updates `modules.ts` and `routes.ts`.

## Run locally

Use Node.js 20.19+ or 22 LTS and pnpm 10.32.1.

```sh
pnpm run install:all
pnpm run hooks:install # From the Git checkout
```

Run `pnpm run server` and `pnpm run web` in separate terminals. Open the URL that Vite prints. The frontend defaults to `http://localhost:4000` for the API. To use another port, set `PORT` for Express and `VITE_API_URL` for Vite.

Open the login page and use either fixed demo account with password `demo123`.

| User | Accessible modules | Actions |
|---|---|---|
| sara | Grievances and Cairo Facilities | Approve grievances, activate Cairo facilities |
| omar | Inspections and Alexandria Facilities | Complete inspections, deactivate Alexandria facilities |

Facilities is the common module. Its table includes region, manager, category, risk, employees, license, address, and last inspection. CASL conditions filter rows on Express and check per-record action buttons through `@casl/react`. Nested detail endpoints and mutation endpoints enforce the same rules. Logging out revokes the session. Logging in reloads the app so cached data is cleared between users.

Credentials, bearer sessions, and records are held in memory for this POC. Restarting Express resets changes and sessions.

## Verify the module boundaries

```sh
pnpm check
pnpm --dir web demo:boundary
pnpm --dir web demo:remove-module grievances
pnpm --dir web demo:remove-module inspections
pnpm --dir web demo:remove-module facilities
```

Lefthook runs staged frontend lint and the dependency graph check at commit time. Pre-push runs the full frontend check and the Express typecheck.

Each removal demo works in a temporary copy. It drops the module imports and entries from `web/src/modules.ts` and `web/src/routes.ts`, deletes the module folder, and rebuilds the frontend. It then checks that the removed route and API client are absent from the build and that each remaining module still has its own route chunk. Express remains a separate process with its demo endpoints.

## Commit messages

Lefthook validates every commit message. Use a type and title, then a blank line and a description. Allowed types are `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, and `revert`. A scope such as `feat(facilities)` and a breaking-change marker such as `feat!` are optional.

```sh
git commit -m "feat(facilities): add region filtering" -m "Filter facilities by the signed-in user's region and enforce access on the API."
```

A title without a description is rejected.
